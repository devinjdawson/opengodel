# AUM: Brokerage AUM Command

AUM is the Godel Terminal command for viewing connected-brokerage asset totals: either the aggregate across all Godel users or your own linked accounts.

## How to use AUM

**Command:**

AUM

![Godel Terminal command bar showing AUM typed with the COMMANDS autocomplete suggesting 'Display personal or global Godel linked brokerage value'](./AUM Command (Brokerage AUM) _ Godel Terminal Docs_files/aum-01.png)

Switch between the two tabs at the top of the window:

![AUM Global tab showing $120.3M Godel user connected AUM across 547 connected brokerage users with a stale data cutoff timestamp](./AUM Command (Brokerage AUM) _ Godel Terminal Docs_files/aum-02.png)

### Global

Shows the total USD AUM across every connected Godel user, together with the number of connected brokerage users and the timestamp of the last refresh ("Stale Data Cutoff"). Individual user balances are refreshed approximately every 24 hours.

**Availability:** Global AUM requires a paid Godel account. Anonymous and free (piker) users see an upgrade prompt on this tab.

### Personal

Shows the combined USD value of every brokerage you have linked through [BROK](https://godelterminal.com/docs/commands/brok.html "BROK command reference"), the timestamp it was last refreshed, and whether the brokerage discount threshold is met.

**Brokerage discount:** if you hold over **$5,000 USD** (or equivalent) across your linked brokerages **and** have made at least **one eligible trade in the past month**, the discount threshold shows **Yes**.

![AUM Personal tab showing connected brokerage AUM of $12.9K and Brokerage Threshold Met: Yes](./AUM Command (Brokerage AUM) _ Godel Terminal Docs_files/aum-personal.png)

**Availability:** Personal AUM requires a logged-in account. Anonymous users see a sign-up prompt.

## Info Panel

Click the **ⓘ** icon in the top-right corner of either tab to overlay a short explanation of what the displayed number means.

## Refresh

Use the refresh icon in the bottom-right status bar to re-fetch the current tab's data.
