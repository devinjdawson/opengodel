# ERN: Earnings Estimates Command

ERN is the Godel Terminal command for viewing analyst consensus earnings estimates alongside the company's estimate-vs-actual track record.

![ERN command showing analyst consensus earnings estimates with low, high, average EPS, forward P/E, and historical estimate versus actual results](./ERN Command (Earnings Estimates) _ Godel Terminal Docs_files/ern-01.png)

## How to use ERN

**Security Identifier/Ticker Country/Instrument Asset Class ERN**

Example: META US EQ ERN: shows Meta's earnings estimates and history.

![ERN command showing the META US EQ ERN launch example for Meta earnings estimates and earnings history](./ERN Command (Earnings Estimates) _ Godel Terminal Docs_files/ern-02.png)

## Header Bar

Across the top, ERN shows:

* **Found**: total number of estimate + history rows in the window.
* **Name**: ticker and full company name.
* **Exchange**: primary listing exchange.
* **FY End**: fiscal-year-end month.

A **date range picker** (start / end) narrows the historical earnings section only. By default the range is five years back to today. The **QuickQuote** chip on the right of the toolbar shows the current live price.

![ERN command header bar showing found count, Meta company name, exchange, fiscal year end, date range picker, and QuickQuote price chip](./ERN Command (Earnings Estimates) _ Godel Terminal Docs_files/ern-03.png)

## Earnings Estimates Table

| Column | Description |
| --- | --- |
| **Period** | Quarter or fiscal year (e.g. "Q3 FY25", "FY2026") |
| **Date** | Month and year the estimate is for |
| **Analysts** | Number of analysts contributing to the consensus |
| **Low** | Lowest individual EPS estimate |
| **High** | Highest individual EPS estimate |
| **Avg** | Consensus (average) EPS estimate |
| **Fwd P/E** | Last price ÷ consensus estimate (full-year estimates only) |
| **EPS YoY** | Consensus EPS vs. the year-ago actual, color-coded green/red for positive/negative growth (full-year estimates only) |

Quarterly rows show **N/A** in the Fwd P/E and EPS YoY columns: those metrics are computed on full-year numbers only.

## Earnings History Table

Below the estimates, ERN lists each past earnings report in the selected date range:

| Column | Description |
| --- | --- |
| **Period** | Quarter / fiscal year identifier |
| **Filing Date** | Date of the earnings release |
| **Estimate** | Consensus EPS estimate going in |
| **Actual** | Reported EPS |
| **Difference** | Absolute beat / miss in EPS |
| **Diff** | % beat / miss, color-coded: green for a beat, red for a miss, gray for in-line |

## Notes

* ERN is in beta.
* If there are no analyst estimates for a security (e.g. very small caps, non-equity assets), the window shows "No earnings or estimates found for this security".

## FAQ

What does ERN do?

ERN is the Godel Terminal earnings estimates command.

How do I open ERN in Godel Terminal?

Type ERN in the terminal, or prefix with a ticker (for example, META US EQ ERN).

Is ERN available on all plans?

Yes, ERN is available on every Godel plan.

Does ERN work for ETFs, indices, or non-US securities?

ERN is built around individual equities. ETFs and indices do not carry this data, so it is stock-focused; non-US companies appear where the underlying data is available.
