# GLCO: Global Commodity Futures Command

GLCO is the Godel Terminal command for monitoring global commodity futures across Energy, Metals, Meat, Grain, and Softs categories.

[![](../../assets/docs/glco/glco-01.png)](../../assets/docs/glco/glco-01.webm)

*Note: A "D" next to any ticker indicates that quote is delayed.*

## How to use GLCO

**Command:**

GLCO

![Launches the Global Commodity Futures component.](./GLCO Command (Global Commodity Futures) _ Godel Terminal Docs_files/glco-02.png)

Launches the Global Commodity Futures component.

### Navigation

Click any ticker to open its chart view by default. This click behavior for GLCO can be customized in your settings (accessible via the command [PDF](https://godelterminal.com/docs/commands/pdf.html "PDF command reference")).

![GLCO command showing global commodity futures prices for crude oil, natural gas, gold, silver, copper, and agricultural products](./GLCO Command (Global Commodity Futures) _ Godel Terminal Docs_files/glco-03.png)

## FAQ

What does GLCO do?

GLCO is the Godel Terminal global commodity futures command.

How do I open GLCO in Godel Terminal?

Type GLCO in the terminal.

Is GLCO available on all plans?

GLCO requires a paid plan. Free (piker) accounts cannot open it.

Does GLCO work for ETFs, indices, or non-US securities?

GLCO is built for global commodity futures across energy, metals, meat, grain, and softs. It is not for equities, ETFs, or indices.
