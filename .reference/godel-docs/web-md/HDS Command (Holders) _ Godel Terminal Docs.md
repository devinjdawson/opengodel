# HDS: Holders Command

HDS is the Godel Terminal command for viewing institutional ownership for any company: owner name, market value, share amount, change, and change percentage.

![HDS command showing institutional holders list for a company with shares held, percent of float, and filing date](./HDS Command (Holders) _ Godel Terminal Docs_files/hds-01.png)

## How to use HDS

**Security Identifier/Ticker Country/Instrument Asset Class HDS**

Example: NVDA US EQ HDS

![HDS command showing the top institutional owners and recent position changes](./HDS Command (Holders) _ Godel Terminal Docs_files/hds-02.png)

*You can use up or down arrow keys to go through the list. If you click “Enter,” it will take you to the original form 13F filing.*

## Treemap

To view a treemap visualization of HDS , click "View as Chart."

![HDS command transitioning from the holders table to the View as Chart control and treemap visualization](./HDS Command (Holders) _ Godel Terminal Docs_files/hds-03.gif)

You can also download the holder table directly from HDS using the download button.

![HDS command showing the download button for exporting holder table data](./HDS Command (Holders) _ Godel Terminal Docs_files/hds-05.png)

## FAQ

What does HDS do?

HDS is the Godel Terminal holders command.

How do I open HDS in Godel Terminal?

Type HDS in the terminal, or prefix with a ticker (for example, NVDA US EQ HDS).

Is HDS available on all plans?

Yes, HDS is available on every Godel plan.

Does HDS work for ETFs, indices, or non-US securities?

HDS is built around individual equities. ETFs and indices do not carry this data, so it is stock-focused; non-US companies appear where the underlying data is available.
