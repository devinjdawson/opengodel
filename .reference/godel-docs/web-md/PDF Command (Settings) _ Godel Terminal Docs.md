# PDF: Settings Command

PDF is the Godel Terminal command for opening your personal user settings and preferences: appearance, default layouts, data feed settings, and keyboard behavior.

## How to use PDF

**Command:**

PDF

![Godel Terminal command bar showing PDF typed with the COMMANDS autocomplete suggesting 'Settings for your user account'](./PDF Command (Settings) _ Godel Terminal Docs_files/pdf-01.png)

## Sections

### Colors

* **Color presets**: pick a packaged Godel theme. Selecting one rewrites all four color values below.
* **Primary color**: accent color used for active states, highlights, and chart primary lines.
* **Positive color**: used for price-up / gain rows.
* **Negative color**: used for price-down / loss rows.
* **Background color**: terminal background.

All color changes save immediately; a toast reminds you that some components require a refresh to fully pick up the new palette.

### Display Options

* **Font**: pick one of: **Oxygen Mono**, **IBM Plex Mono**, **JetBrains Mono**, **Doto**.
* **Table animation**: how new rows animate into data tables (e.g. in [N](https://godelterminal.com/docs/commands/n.html "N command reference")). Options: **No animation**, **Fade**, **Flip Board**, **Left Slide**, **Lightning**, **Red Alert**.
* **Snap windows to grid**: enable grid snapping and configure the grid size (2 to 50 px). While dragging the slider, a preview grid is drawn over the terminal.
* **Terminal zoom** (experimental): scales the terminal input and top navigation (1× to 3×). Increasing zoom hides parts of the top bar.
* **Show help button in window title bar**: if on, commands with published docs get a help icon that opens this documentation site.

### Keyboard Overrides

* **Terminal Key**: rebind the key used to focus the terminal input (default `  `). Click the field, press the new key, then **Save**. Reset` returns to the default.

### Command Settings

* **Show exchange in CHAT tickers**: displays the listing exchange alongside tickers referenced in chat.
* **Show DES intraday graph by default**: opens the [DES](https://godelterminal.com/docs/commands/des.html "DES command reference") chart with the intraday timeframe instead of 1-year.
* **Command Titles**: what to render in window title bars: **Use Title**, **Use Shortcut**, or **Hide**.
* **Show help icon in toolbar**: per-window docs icon.
* **Show popout icon in toolbar**: per-window popout icon.

### Breaking News

* **Show breaking news**: turn the red breaking-news banner on or off.
* Related breaking-news filter controls let you tune which sources / categories trigger a banner.

### Ticker Click Behavior

For every list-style component that displays clickable tickers ([QM](https://godelterminal.com/docs/commands/qm.html "QM command reference"), [MOST](https://godelterminal.com/docs/commands/most.html "MOST command reference"), [WEI](https://godelterminal.com/docs/commands/wei.html "WEI command reference"), [WEIF](https://godelterminal.com/docs/commands/weif.html "WEIF command reference"), [GLCO](https://godelterminal.com/docs/commands/glco.html "GLCO command reference"), [HALT](https://godelterminal.com/docs/commands/halt.html "HALT command reference"), [TREND](https://godelterminal.com/docs/commands/trend.html "TREND command reference"), [FOCUS](https://godelterminal.com/docs/commands/focus.html "FOCUS command reference"), [CHAT](https://godelterminal.com/docs/commands/chat.html "CHAT command reference")), PDF lets you pick which command each click opens. Supported defaults per source:

| Source | Default click target |
| --- | --- |
| **CHAT** | DES |
| **QM** | G |
| **MOST** | DES |
| **WEI** | G |
| **FOCUS** | DES |
| **TREND** | DES |
| **GLCO** | G |
| **WEIF** | DES |
| **HALT** | DES |

You can change any of these to another supported command (e.g. open [G](https://godelterminal.com/docs/commands/g.html "G command reference") instead of [DES](https://godelterminal.com/docs/commands/des.html "DES command reference") when clicking a MOST ticker).

### Pinned Commands

Pin your most-used commands to the top navigation so they're one click away. Pinned commands render as shortcut chips next to the terminal input.

### Other

* **Trust external links**: controls whether external links open directly or prompt for confirmation.

## Notes

* Most changes save and apply instantly; a few (theme colors, table animations) prompt you to refresh for full effect.
* Preferences sync with your user account, so the same theme, keybinds, and click behavior follow you across devices and browsers.
