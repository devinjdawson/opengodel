# TRAN: Earnings Hub Command

TRAN is the Godel Terminal command for searching earnings calls: full-text search across firms, quarters, and years with direct-link citations.

![TRAN command showing Apple's Q2 2026 earnings conference call transcript with the transcript index on the left, company header, and the Final Transcript reader pane listing Corporate Participants](./TRAN Command (Earnings Hub) _ Godel Terminal Docs_files/tran-01.png)

## How to use TRAN

**Global view:**

TRAN: lists every recent transcript across all covered companies.

![Godel Terminal command bar showing TRAN typed with the COMMANDS autocomplete suggesting 'Access earnings calls for leading companies'](./TRAN Command (Earnings Hub) _ Godel Terminal Docs_files/tran-02.png)

**Company view:**

**Security Identifier/Ticker Country/Instrument Asset Class TRAN**

Example: AAPL US EQ TRAN: Apple's earnings calls, with the most recent opened by default.

![Godel Terminal command bar showing AAPL US EQ TRAN typed with the COMMANDS autocomplete suggesting 'Access earnings calls for leading companies'](./TRAN Command (Earnings Hub) _ Godel Terminal Docs_files/tran-03.png)

## Layout

* **Transcript index** (left side): chronological list of available transcripts. Each entry shows the title and publication date.
* **Reader pane**: the full text of the selected transcript, rendered with styled paragraphs for speaker turns, Q&A, and disclaimers.

When the command is opened on a specific ticker, a **company header** is also shown above the reader:

* Company logo
* Full company name
* Ticker symbol
* Live **QuickQuote** price
* Website link (opens in a new tab)

## Navigation

* Click any row in the index to load that transcript.
* Scroll to the bottom of the index to pull in older transcripts: the list paginates in chunks of 200.
* Loading indicators appear on both the index (when paging) and the reader (when switching transcripts).

![TRAN navigation: clicking through the transcript index cycles through the MZTI, TSN, FSTR, KRYS, and NCLH earnings calls](./TRAN Command (Earnings Hub) _ Godel Terminal Docs_files/tran-nav.gif)

## Notes

* Transcripts are sourced from the same news feed that powers [N](https://godelterminal.com/docs/commands/n.html "N command reference") (category: Transcripts).
* Large pages may take a moment to render on first load.

## FAQ

What does TRAN do?

TRAN is the Godel Terminal earnings hub command.

How do I open TRAN in Godel Terminal?

Type TRAN in the terminal, or prefix with a ticker (for example, NVDA US EQ TRAN).

Is TRAN available on all plans?

Yes, TRAN is available on every Godel plan.

Does TRAN work for ETFs, indices, or non-US securities?

TRAN is built around individual equities. ETFs and indices do not carry this data, so it is stock-focused; non-US companies appear where the underlying data is available.
