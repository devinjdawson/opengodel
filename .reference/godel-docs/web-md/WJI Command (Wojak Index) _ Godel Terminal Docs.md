# WJI: Wojak Index Command

WJI is the Godel Terminal command for viewing the live Wojak Index: a real-time sentiment gauge built from Pink/Green wojak emoji usage in Godel's #general chat.

![WJI command showing the live Wojak Index measuring pink and green wojak balance in the #general chat feed](./WJI Command (Wojak Index) _ Godel Terminal Docs_files/wji-01.png)

## How to use WJI

**Command:**

WJI

![Launches the Wojak Index](./WJI Command (Wojak Index) _ Godel Terminal Docs_files/wji-02.png)

Launches the Wojak Index

### Display Components

* **Gauge:** A semicircular meter showing current sentiment. The needle moves from left (green/bullish) to right (pink/bearish), and the arc color follows the current reading.
* **Bull/Bear Ratio:** Percentage split between bullish and bearish emotes at the top of the component.
* **Wojak:** Image state that changes based on the current sentiment level.

### Info Panel

Click the **info icon** (ⓘ) in the top-right corner to toggle detailed emote counts.

![WJI command transitioning from the main Wojak Index view to the info icon and expanded emote-count panel](./WJI Command (Wojak Index) _ Godel Terminal Docs_files/wji-03.webp)

When expanded, the panel shows raw counts: Bulls, Bears, Pink, and Green emotes from the sample.
